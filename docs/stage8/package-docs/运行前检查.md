# ControlDoor 运行前检查

## 自动检查

在发布包根目录执行：

```powershell
.\ControlDoor.exe --validate-config
```

验证模式只做运行前检查，不启动 gRPC 服务，不启动设备 worker，不下发任何设备操作。

## 必须通过项

| 项目 | 通过标准 |
| --- | --- |
| 配置文件 | `Configuration\appsettings.json` 存在，JSON 可解析。 |
| gRPC 端口 | `Service.GrpcListenPort` 在 1-65535，且未被占用。 |
| 数据库 | 连接成功，`dbo.system_users`、`dbo.attendance_gate_v2`、`dbo.device_operation_retry_states` 可读。 |
| 设备清单 | `Configuration\devices.json` 存在且可解析；设备条目包含合法 `types`。 |
| 阶段 6 表 | 启用离线补偿时 `dbo.device_operation_retry_states` 可读。 |
| 阶段 7 表 | 启用人脸事件时 `dbo.attendance_gate_v2` 可读。 |
| 日志目录 | `Logging.LogDirectory` 可创建且可写；默认 `D:\ControlDoorData\logs`。 |
| 诊断日志目录 | 日志根目录下的 `diagnostic` 子目录可创建且可写；与日常日志分别检查。 |
| SDK 日志目录 | `HikvisionSdk.SdkLogDirectory` 可创建；`RequireSdkLog=true` 时必须可写；默认 `D:\ControlDoorData\logs\sdk`。 |
| 抓拍目录 | `FaceEventLogging.SnapshotRootDirectory` 可创建且可写；默认 `D:\ControlDoorData\snapshots`。 |
| SDK DLL | 找到 `HCNetSDK.dll`。 |
| SQL Server Types | 找到 `SqlServerTypes`。 |

## 人工确认项

| 项目 | 确认 |
| --- | --- |
| SDK 位数 | 与服务进程平台一致。 |
| 设备白名单 | 仅包含允许真实联调的设备 ID/IP。 |
| 测试员工 | 使用专用测试员工、权限和人脸图片。 |
| 日志策略 | 确认 `Logging.LogDirectory`、`RetentionDays`、`MinimumLevel` 和慢操作阈值符合现场要求。 |
| 密钥 | 仓库模板中不得出现真实数据库密码和正式 API Key。 |

## 失败处理

validate 失败时不要安装或启动服务。先根据失败项处理配置、端口、数据库、目录权限或 SDK DLL，再重新执行 `ControlDoor.exe --validate-config`。

## gRPC payload 日志确认

默认发布模板将日常日志和诊断日志同时写入两份文件。日常文件为 `Logging.LogDirectory\ControlDoor-yyyyMMdd.log`，记录中文关键状态、同步批次结果、门禁联动和异常。诊断文件为 `Logging.LogDirectory\diagnostic\ControlDoor-diagnostic-yyyyMMdd.log`，记录结构化详细过程、报文和异常堆栈。达到单文件大小限制后追加 `-001` 等序号。

| 配置项（均位于 `Logging`） | 默认值 | 检查内容 |
| --- | --- | --- |
| `MinimumLevel` / `DiagnosticMinimumLevel` | `Info` / `Debug` | 两份输出独立过滤；日常阈值不会丢弃诊断细节。 |
| `RetentionDays` / `DiagnosticRetentionDays` | 30 / 7 | 最长保留天数。 |
| `MaxTotalSizeMB` / `DiagnosticMaxTotalSizeMB` | 512 / 2048 | 两类应用日志各自的容量上限，MB 按 1024×1024 字节计算。 |
| `MaxFileSizeMB` | 20 | 两类文件均按日期和大小滚动；单文件上限不会超过对应总量上限。 |
| `EnableGrpcPayloadLogging` / `GrpcPayloadLogMode` | `true` / `Full` | 诊断文件保留详细报文；关闭开关后不再输出报文占位日志。 |
| `IncludeCredentialFields` / `IncludeFaceImageBase64` | `false` / `false` | 默认凭据打码，图片仅记录 Base64 长度。已有配置若显式为 `true`，升级前应改为 `false`。 |
| `MaxPayloadChars` | 16384 | 脱敏后限制报文正文长度，超限附加截断标记及原始长度；截断内容不保证仍为完整 JSON。 |
| `EnableSdkTrace` | `true` | 控制应用诊断中的 SDK 调用跟踪；与海康 SDK 自身日志独立。 |
| `SlowOperationThresholdMs` | 1000 | 达到阈值的操作进入日常告警。 |

达到保留天数或容量限制时先清理最旧的本组件日志，所以天数不保证能全部留足。启动、滚动和持续写入期间至少每分钟检查清理；容量达到上限时也触发清理。海康原生日志 `HikvisionSdk.SdkLogDirectory` 不计入上述容量上限。

配置在启动时加载，修改后需重启服务。正常状态查询、轮询、逐次刷脸和内部调度进入诊断文件；同步结果中的“待补偿”不表示已经完成设备下发。自动重连、布防探测等持续告警首次立即写入日常文件，重复记录按 60 秒窗口汇总；诊断文件保留每次记录。
